# Contribuer

1. Lire `CLAUDE.md`, en particulier les règles de sécurité.
2. Écrire des modules petits, avec une API publique documentée et des erreurs explicites.
3. Lancer `scripts/test` et `scripts/lint` avant toute proposition.
4. Enregistrer dans `DECISIONS.md` tout changement d'architecture.
5. Ne jamais ajouter de dump, de base IDA ni de code NumWorks.
